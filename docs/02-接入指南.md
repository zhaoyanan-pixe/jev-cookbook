# 02 · 接入指南：30 分钟挂上第一个判定点

> 本篇全部代码都经过真实跑通（文末附我们的实测输出）。

## 你需要准备什么

- **一个判定器入口**（二选一）：
  - **TypeSafe 直连**（官方，推荐）：`https://api.typesafe.ai/v1/systemone`
  - **OpenRouter 聚合**：`https://openrouter.ai/api/alpha/decisions`（模型名 `~typesafe/jev-latest`）
  - 起步想省钱：部分聚合平台会提供 Jev 的**免费入口**（如 OpenCode Zen 曾提供免费的 Jev；平台政策可能变化，以当页说明为准）。
- **Python 3.10+**（本手册示例全部只用标准库，不装任何依赖）。

## 第三步：认识三种问法（格式 100% 验证过）

请求只有一个形态：**state（被评估的内容）+ questions（一问一组小问题）**：

```python
payload = {
    "state": "被评估的内容，可以是文本，也可以是结构化数据",
    "model": "jev-latest",
    "questions": {
        # 1) 是/否（noul）：返回 0-1 概率
        "is_risky": {
            "type": "noul",
            "instructions": "这条命令是否会带来不可逆的数据损失？",
        },
        # 2) 选一个（choice）：criteria 是「选项 -> 说明」的字典
        "which_to_read": {
            "type": "choice",
            "instructions": "下面哪条内容与目标问题的相关度最高？",
            "criteria": {
                "第 1 条": "只提到相关领域，没有具体信息",
                "第 2 条": "给出了可直接使用的数据",
                "第 3 条": "跑题",
            },
        },
        # 3) 打分（score）：criteria 是「从低到高」的档位数组
        "importance": {
            "type": "score",
            "instructions": "这段资料对『给水管道设计』任务的重要程度？",
            "criteria": ["无关", "背景参考", "直接可用"],
        },
    },
}
```

调用（纯标准库，完整版见 `scripts/jev_smoke.py`）：

```python
import json, os, urllib.request

def jev(questions, state, model="jev-latest"):
    key = os.environ["TYPESAFE_API_KEY"]
    req = urllib.request.Request(
        "https://api.typesafe.ai/v1/systemone",
        data=json.dumps({"state": state, "model": model, "questions": questions},
                        ensure_ascii=False).encode(),
        method="POST",
        headers={"Authorization": f"Bearer {key}", "content-type": "application/json"},
    )
    with urllib.request.urlopen(req, timeout=10) as r:
        return json.loads(r.read())
```

### 失败安全三件套（必须有）

1. **超时预算**：给判定调用设短超时（我们设 ~3 秒），超时**就当作"没有判定器"**，走原路径；
2. **熔断**：连续失败（比如 3 次）→ 静默跳过一段时间（比如 2 分钟），期间不再尝试；
3. **fail-open 铁律**：任何异常绝不阻断主流程。判定器是"外挂"，不是"心脏"。

## 第五步：记"账本"

每条判断都记一行：**时间 / 问什么 / 答案 / 概率 / 后来实际对不对**。

这份账本是下一步（放权）唯一的依据——没有它，你只是"感觉它挺准"；有了它，你能说"这类问题 30 天里对了 96%，可以放权；那类只有 55%，继续影子"。
